# 🌐 Building REST APIs with FastAPI

## 🎯 Objective

Build a small REST API with FastAPI and practice defining routes, validating request data, and returning JSON responses.

## 📝 Tasks

### 🛠️ Create the API

#### Description

Implement a FastAPI service that manages a collection of printing project ideas.

#### Requirements

Completed program should:

- Define a health-check endpoint.
- Provide endpoints to list and create project ideas.
- Validate incoming JSON with a typed request model.
- Return clear HTTP status codes and JSON responses.

### 🛠️ Add validation

#### Description

Improve the API so invalid project names and descriptions receive helpful validation errors.

#### Requirements

Completed program should:

- Reject empty project names.
- Return a helpful error message for invalid input.
- Keep the API behavior documented in the README.
